# Практическая работа 18

## Что нужно было сделать

Нужно было подготовить контрольную работу №3.

В нее входят практические работы:

- 13PR
- 14PR
- 15PR
- 16PR
- 17PR

## Что находится в работах

### 13PR

Простое приложение с заметками.

Можно добавить заметку, и она сохраняется в браузере.

### 14PR

То же приложение, но уже как PWA.

Добавлены:

- manifest;
- иконки;
- service worker.

### 15PR

Добавлена загрузка страниц из папки `content`.

Есть главная страница и страница с описанием.

### 16PR

Добавлен сервер.

Также есть:

- Socket.IO;
- push-уведомления;
- работа через service worker.

### 17PR

Добавлены напоминания.

Можно создать заметку и выбрать время напоминания.

## Как запустить

Для простых работ можно открыть `index.html`.

Для работ с сервером нужно выполнить:

```powershell
npm install
npm start
```

После запуска открыть адрес из консоли.

Обычно это:

```text
http://localhost:3001
```
